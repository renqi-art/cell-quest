# 演示故障切换手册

1. 在线 AI 正常：危机卡显示“在线 AI”，继续演示。
2. 在线 AI 超时或返回非法蓝图：指出危机卡已显示“本地导演”，不刷新、不换病例，继续同一局。
3. 公共站点不可用：30 秒内在已校验离线包目录运行 `node server.cjs`，打开 `http://127.0.0.1:4173`。
4. 离线运行也不可用：立即播放已归档的 90 秒录制，并打开 `docs/evidence/screenshots/` 中的编辑器和病例备份图。

切换时只说真实来源。不要展示终端环境变量、API Key、个人绝对路径或私有聊天。彩排必须分别覆盖在线正常、AI 超时、公网站点不可用三种模式。
