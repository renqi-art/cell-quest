# 四分钟现场演示脚本

| 时间 | 操作与讲解 |
|---|---|
| 0:00–0:20 | 打开病例中心：同一名患者从擦伤、感染、缺氧到康复。 |
| 0:20–0:45 | 启动第一章，指出氧供/感染/组织指标与稳定倒计时。 |
| 0:45–1:20 | 展示 AI 危机卡，明确说出“在线 AI”或“本地导演”来源及安全白名单。 |
| 1:20–3:00 | 展示红细胞运输、白细胞清除和第五章双人协作；失败时直接切到确定性演示存档。 |
| 3:00–3:30 | 打开病例结算和知识来源，强调游戏化指标及科普免责声明。 |
| 3:30–3:55 | 在 Vue 病例设计器用 AI 生成受限蓝图，校验、试玩并 CQ2 导出。 |
| 3:55–4:15 | 打开证据入口，说明测试、离线包、AI 开发边界和社会价值。 |

硬上限 4 分 30 秒。3:30 之后可跳过编辑细节，直接展示已准备的有效病例与 CQ2。
