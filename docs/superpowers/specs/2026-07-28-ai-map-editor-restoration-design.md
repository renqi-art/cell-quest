# 地图编辑器 AI 生成恢复设计

## 1. 背景

经典地图编辑器曾提供“AI 生成”按钮，由浏览器直接读取保存在
`localStorage` 中的 DeepSeek API Key，并直接请求模型。该实现后来在
`897c167 security: remove browser AI credentials` 中停用，原因是浏览器持有长期
API Key 会造成泄露风险。

本次只恢复经典地图编辑器 `editor.html` 中的 AI 地图生成功能，不恢复游戏主界面
的 AI 生成入口，也不改变病例设计器的 AI 病例生成能力。

## 2. 目标

- 在地图编辑器工具栏恢复“🤖 AI生成”按钮。
- 使用工具栏当前宽高生成地图，支持宽 `20–200`、高 `10–80`。
- 生成结果先预览，只有用户确认后才替换当前地图。
- 模型 API Key 只存在服务端环境变量或服务端运行内存中。
- 未配置 Key 时提示用户，并跳转到项目内的 AI 配置页。
- 不提供本地模板回退；无法完成真实 AI 生成时明确报错。
- 生成结果必须符合经典字符地图格式和编辑器现有瓦片集合。

## 3. 非目标

- 不恢复游戏 Hub 中的 AI 关卡生成面板。
- 不在浏览器 `localStorage`、`sessionStorage`、Cookie 或页面源码中保存 API Key。
- 不让模型直接输出可执行 JavaScript。
- 不修改病例设计器的 `/api/generate-case` 行为。
- 不重构整个经典编辑器或迁移其内联脚本。
- 不处理与本功能无关的现有工作区改动。

## 4. 方案选择

### 4.1 未采用：浏览器直连模型

该方案最接近旧实现，但需要浏览器持有 API Key，会重新引入已修复的凭据泄露风险。

### 4.2 未采用：模型直接输出完整字符地图

该方案实现简单，但当前编辑器允许最大 `200×80`。完整地图响应容易超过模型输出
长度，也容易出现缺行、行宽不一致、非法瓦片、缺少出生点或不可用布局。

### 4.3 采用：AI 蓝图 + 确定性地图编译器

模型只生成紧凑、受约束的关卡蓝图。服务端验证蓝图后，由本地确定性编译器按照请求
宽高生成完整字符地图。这保留 AI 对主题和关卡结构的设计作用，同时保证输出尺寸和
基础结构合法。

## 5. 用户流程

1. 用户在工具栏设置地图宽高。
2. 用户点击“🤖 AI生成”。
3. 编辑器请求 `GET /api/ai-config`。
4. 如果未配置 Key，页面显示提示并跳转到
   `ai-settings.html?return=%2Feditor.html`。
5. 配置完成后，用户返回编辑器并重新点击 AI 生成。
6. 编辑器打开生成弹窗，用户输入自然语言描述。
7. 编辑器提交提示词和当前宽高到 `POST /api/generate-map`。
8. 服务端调用模型生成蓝图、验证蓝图并编译地图。
9. 弹窗显示地图名称、尺寸、主要属性和 Canvas 缩略预览。
10. 用户点击“应用到编辑器”后，结果才替换当前网格、地图名称和相关关卡属性。
11. 用户取消、关闭弹窗或请求失败时，当前地图保持不变。

## 6. 服务端组件

### 6.1 AI 运行时配置

新增独立配置模块，负责：

- 读取启动时的 `CELL_QUEST_AI_API_KEY`。
- 在服务端内存中保存用户运行时设置的 Key。
- 运行时 Key 优先于环境变量 Key。
- 服务端重启后清除运行时 Key。
- 提供“是否已配置”状态，不提供读取 Key 的接口。
- 清除运行时 Key 后，如果存在环境变量 Key，状态仍为已配置。

配置接口：

- `GET /api/ai-config`
  - 返回 `{ "configured": boolean, "source": "runtime" | "environment" | "none" }`。
  - 永不返回 Key、Key 前缀或长度。
- `POST /api/ai-config`
  - 只接受 JSON `{ "apiKey": string }`。
  - 非空值设置运行时 Key；空字符串清除运行时 Key。
  - 对请求体大小和 Key 长度设置上限。
  - 不记录请求体和 Key。

服务端继续默认绑定 `127.0.0.1`。接口使用现有同源策略和 JSON
`Content-Type` 检查，不增加跨域许可。

### 6.2 AI 地图蓝图生成器

新增 `POST /api/generate-map`，请求结构为：

```json
{
  "prompt": "血液循环中的细菌感染",
  "width": 135,
  "height": 30
}
```

约束：

- `prompt` 去除首尾空白后必须为 `1–1000` 个 UTF-16 代码单元。
- `width` 必须为 `20–200` 的整数。
- `height` 必须为 `10–80` 的整数。
- 生成接口请求体上限为 `16 KiB`，模型文本响应上限为 `64 KiB`。
- 未配置 Key 时返回可识别的 `AI_NOT_CONFIGURED` 错误。
- 模型请求设置超时，并复用
  `CELL_QUEST_AI_BASE_URL`、`CELL_QUEST_AI_MODEL` 配置。

模型只允许返回固定字段：

- `name`
- `theme`
- `cellType`: `1` 或 `3`
- `difficulty`: `easy`、`normal` 或 `hard`
- `platformDensity`
- `enemyDensity`
- `itemDensity`
- `regions`: 有界的区域风格列表

`name` 最长 40 个代码单元，`theme` 最长 120 个代码单元，`regions` 最多 8 项且
每项最长 80 个代码单元；三个密度字段都必须是 `0–1` 的有限数。验证器拒绝未知
字段、越界数值、过长文本和包含脚本形态的文本。

### 6.3 确定性地图编译器

编译器接收已验证蓝图、宽、高和稳定种子，输出：

- 精确 `height` 行。
- 每行精确 `width` 个字符。
- 只包含编辑器 `TILES` 已支持的字符。
- 至少一个 `P` 出生点和一个 `F` 终点。
- 连续的基础地面。
- 从出生区到终点区的主路径。
- 符合密度参数的平台、敌人、陷阱和收集物。

编译器不执行模型文本，不生成 JavaScript。相同蓝图和种子应产生相同地图，便于测试
和问题复现。

响应结构为：

```json
{
  "ok": true,
  "source": "ai",
  "level": {
    "name": "感染防线",
    "cellType": 1,
    "winCondition": "killAll",
    "width": 135,
    "height": 30,
    "map": ["..."]
  },
  "blueprint": {
    "theme": "血液感染",
    "difficulty": "normal"
  }
}
```

## 7. 前端组件

### 7.1 地图编辑器入口

在 `editor.html` 工具栏“新建”按钮旁恢复“🤖 AI生成”按钮。按钮调用独立命名的
入口函数，避免复用已停用的浏览器直连函数。

### 7.2 AI 生成弹窗

弹窗包含：

- 提示词输入框。
- 当前目标尺寸只读提示。
- 生成、取消按钮。
- 请求中的加载状态。
- 生成后的名称、属性摘要与 Canvas 缩略图。
- “重新生成”和“应用到编辑器”按钮。

生成期间防止重复提交。关闭弹窗时取消尚未完成的请求。

### 7.3 应用规则

生成响应先保存在弹窗的临时状态中，不直接修改全局 `grid`。点击“应用到编辑器”后：

- 把当前 `grid` 保存到 `snapshot`，使现有重置能力可恢复生成前地图。
- 更新 `grid`、`mapWidth`、`mapHeight`。
- 更新宽高输入框和关卡名称。
- 更新可映射的细胞类型和胜利条件。
- 清空与新地图坐标不再匹配的管道、教程和知识卡片配置。
- 调用现有绘制和信息更新逻辑。

如果用户未确认，所有编辑器状态保持不变。

### 7.4 AI 配置页

新增 `ai-settings.html`，视觉上沿用经典编辑器样式。页面提供：

- 当前状态：未配置、环境变量配置或运行时配置。
- 密码类型的 API Key 输入框。
- 保存、清除运行时 Key、返回编辑器按钮。
- 安全说明：Key 仅发送到本机服务端内存，服务重启后运行时 Key 会消失。

页面不回显已配置 Key，不把 Key 放入 URL、DOM 持久状态或浏览器存储。

## 8. 错误处理

- `AI_NOT_CONFIGURED`：提示配置，并提供跳转按钮。
- 上游鉴权失败：提示 Key 无效或无权限，保留当前地图。
- 上游限流或服务错误：显示可重试提示。
- 超时：显示超时提示，允许重新生成。
- 蓝图 JSON 或字段无效：返回受控格式错误，不尝试执行或宽松解析。
- 地图编译或最终校验失败：不返回半成品地图。
- 网络断开或用户取消：弹窗恢复可操作状态，不覆盖当前地图。

所有错误响应使用稳定错误码和面向用户的中文消息；服务端日志不得包含 API Key。

## 9. 安全约束

- 浏览器不直接请求 DeepSeek 或其他模型上游。
- API Key 不进入 `localStorage`、`sessionStorage`、Cookie、查询参数或响应。
- 模型输出按数据处理，不使用 `eval`、`Function` 或动态脚本插入。
- 请求体、提示词、宽高和模型响应均有上限。
- 地图字符采用允许列表验证。
- 配置和生成接口只接受 JSON。
- 保留现有 CSP 与同源限制。

## 10. 测试策略

### 10.1 服务端单元测试

- 配置状态只暴露来源，不暴露 Key。
- 设置、替换、清除运行时 Key。
- 环境变量与运行时 Key 的优先级。
- 未配置时生成接口返回 `AI_NOT_CONFIGURED`。
- 提示词、宽高和请求体边界验证。
- 模型蓝图未知字段、非法文本和越界密度被拒绝。
- 相同种子生成稳定结果。
- 不同合法宽高得到精确尺寸。
- 最终地图只含允许瓦片，并含 `P`、`F` 和基础主路径。

### 10.2 浏览器测试

- 工具栏显示 AI 生成按钮。
- 未配置时跳转配置页。
- 配置页的 Key 不进入浏览器存储或 URL。
- 生成结果出现后、确认前，编辑器网格不变化。
- 点击应用后，名称、宽高和网格同步更新。
- 取消、超时和错误时保留原地图。
- 浏览器不会直接访问模型上游。

### 10.3 回归验证

- 运行新增的定向测试。
- 运行服务端测试与安全测试。
- 运行类型检查、Lint、构建及与编辑器相关的现有测试。
- 确认 Vite 构建包含 `ai-settings.html`。

## 11. 工作区保护

实施时只修改本功能所需文件。当前工作区中的以下内容不属于本功能，必须保留且不得
混入本功能提交：

- `editor.html` 中现有的自定义关卡存储键修改。
- `js/levels/backup/level0_blood.js`。
- `audit/`。
- `dist/`。

如果需要编辑 `editor.html`，必须在现有未提交内容之上做最小补丁，并在提交前逐段
核对差异。

## 12. 验收标准

- 地图编辑器可见“🤖 AI生成”按钮。
- 无 Key 时能够到达项目内配置页，且不存在浏览器端 Key 持久化。
- 配置 Key 后可按当前宽高请求真实 AI 地图。
- 返回地图经过预览确认后才应用。
- 失败、取消或关闭弹窗不会覆盖现有地图。
- 生成地图尺寸准确、瓦片合法，并包含必要出生点和终点。
- 现有安全测试仍证明浏览器不直连模型上游。
- 用户已有未提交改动完整保留。
